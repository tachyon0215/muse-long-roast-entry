Entry for the make.fun competition [The Long Roast: Lawmakers and the File They Cannot Convert](https://make.fun/bounty/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7).

## Why this line

Candidates: (A) the chosen printer line, (B) chaining the most powerful technology on Earth, pausing to ask an intern about the PDF, (C) regulating any intelligence except the kind needed to export a Word file. A won against the judge brief: it sets up the lawmakers' authority (governing minds, markets and the internet before lunch) and undercuts it with a specific, unexpected detail (begging the office printer, as if the bill were classified), with the punch on the last words.

## How it works

`main.py` (Python 3, standard library only, no network, deterministic) validates the fixed entry line against the competition gate and writes it to `entry.txt` under `MAKEFUN_OUTPUT_DIR` (default `/output`), then reads the file back to verify the bytes.
